# Summarize Slides

把课件整理成可回查、可复习、能重做典型例题的笔记。中文为主，重要术语首次出现时保留原文英文；默认单栏、清晰可读，不为压缩页数牺牲数学条件和解题步骤。用户指定的语言、范围、格式和篇幅优先。

## 1. 确定范围和交付形式

- 从请求确定源文件、全篇或选定范围、语言、输出格式；已有信息足够时直接开始。
- 默认交付 `Summary - <stem>.tex` 与成功编译的 PDF。明确要求 Markdown 时交付同名 `.md`；明确要求直接在聊天中回答时允许聊天输出。
- “personal review notes”“summary-only”仅描述用途或简略程度，不能据此强制选择 Markdown。“不要 PDF”未指定其他格式时，采用 Markdown 并说明选择；“只要 TeX / 不用编译”按原要求保留源文件。
- PDF 输入优先使用可用的 `pdf` 技能处理提取、OCR 和渲染；技能不可用时使用等价的可用工具，并执行下述来源核查。PPTX 输入使用可用的演示文稿工具读取或转换，不能把它当成 PDF；记录转换前后的页码关系。
- 默认在源文件旁创建 `Summary - <stem>/`。用户或宿主指定了输出目录则遵循该目录；源目录只读时使用当前工作区的输出目录并告知。仅有文本时采用课程名，无名称则用 `lecture-slides`。
- 成品与中间文件分开；在选定目录下使用 `work/` 保存提取文本、分段笔记和核查记录，宿主另有临时目录规则时遵循宿主规则。不要覆盖已有成品或修改课件。
- 根据所需格式检查可用输出能力，Markdown/聊天模式不检查 LaTeX。LaTeX/PDF 的输出流程见 [references/output.md](references/output.md)。

## 2. 全局阅读与页码映射

先查看文档总页数、目录和章节边界，再按自然主题分段深读。全篇任务查看全篇页面；选定范围任务只需概览文档结构并逐页读取所选范围，按需回查前置内容，不把范围外内容宣称为已覆盖。短课件可以只有一段；长课件保留分段记录，不能只读开头或仅根据目录总结。

建立覆盖表：`来源文件 | PDF物理页范围 | 主题 | 状态 | 对应笔记章节`。范围包含所选的每一页，状态区分已读取、空白/重复、未能读取；重复和省略需要理由。跨页推导、定理证明和同一例题保持连续，不强行切断。

- 页码统一以 **从 1 开始的 PDF 物理页** 为基准。若幻灯片印刷页码不同，写成 `[课件A, PDF p12 / 幻灯片10]`。不要把提取器的零基索引或输出笔记页数当来源页数。
- 多份课件的引用包含文件简称，文首提供简称对应表。
- 无原始 PDF 时仅引用提供内容中确实存在的页码/小节；没有页码就注明“来源未提供页码”，不得猜测。
- 扫描页、公式、表格和图形需要直接看页面；文字提取为空不代表该页没有知识点。OCR 无法确认的符号局部标记“待核对”，继续处理能确认的内容。若歧义阻碍关键结论，针对该页请求更清晰来源。

每段保存：范围、核心概念及英文名、公式与条件、例题的输入/步骤/结果、技巧/易错点、需要的图示、来源定位、未解决问题。

可用且有助于长篇处理时，将独立主题交给不同 reader；紧密关联的推导串行处理。reader 只写其分段笔记，不写最终成品。没有子代理时顺序完成同一流程。

## 3. 按主题合并复习笔记

按主题组织，不照搬逐页流水账。每个主要主题包含必要的定义、公式、适用情境、代表性例题与易错点；不要为无相关内容的主题机械凑齐栏目。

- 每个来自课件的知识点带精确页码或紧凑范围，不能用整章范围掩盖定位缺失。
- 公式说明符号、前提、单位/维度（适用时）、边界与常见误用；保留老师使用的记号。不同章节记号冲突时解释区别。
- 抽象定义和公式后加一句简明中文释义。口诀只辅助记忆，不替代条件。
- 对课件中的非平凡例题保留输入、关键中间步骤、结果和解题技巧，不能只写“见第X页”。重复题型可合并并列出来源；用户明确要求压缩篇幅时保留代表题并说明合并范围。
- 对数据变换给出小规模输入和输出；数据库/关系代数/SQL 课程按需读 [references/database-examples.md](references/database-examples.md)。其他学科采用适合该领域的数值例、图形或推导，不强制表格化。
- 补充例题、推导和直观解释标为“补充示例/补充解释”，与老师原例区分；可注明所解释的概念页码，但不能暗示新增数据来自该页。
- 来源疑似错误时列出“原文内容—疑点—建议修正及依据”，不要无声改写。不确定的证明或结论不补成事实。
- 图示仅在有助理解时加入，优先可复现绘图；保持标签、坐标、方向和假设准确。不能可靠重建时说明局限，不编造图形。

### 从整理过渡到可复习

- 来源已有总结表时保留其价值与来源，不把重新排版声称为新增知识。按需补充可回查的前提、白话解释和代表题步骤，不为展示整理效果贬低或故意打乱原课件。
- 同族方法适合对比时统一比较维度，把每项成立的条件紧邻结论放置；区分树搜索与图搜索、理论复杂度与实际实现等不同口径。课件简化式与补充精确式分开注明，不静默替换。
- 图解算法、队列变化或逐帧演示按需读取 [references/algorithm-traces.md](references/algorithm-traces.md)，使中间状态可以复算；普通概念课件无需加载。
- 在用户要求自测、主动回忆或可直接复习时，为主要主题附少量自测题，答案集中在后面并标注来源。优先检验适用条件、易混点或一步推理，避免只考术语。新增题标为“补充自测”，不得称为真题或预测考题；未要求时不强制增加练习册。

### 保留重点标签，但不把复习建议包装成押题

沿用 `★必背`、`△理解`、`⚠易错`，每条最多一个，多数条目不必标记。

- `★必背`：优先用于核心公式、封闭命名列表；描述性概念通常用 `△理解`。老师明确要求背诵的定义可例外。
- `△理解`：直觉、推理、比较与适用条件。
- `⚠易错`：来源明确提示或可解释的常见误用，不虚构“历年高频”。

文首说明：除已引用的教师/考试要求外，标签是复习建议，不是已确认的考试范围。保留低密度偏好；80–100 页课件约 8–12 个必背锚点只作过度标注的提醒，不是配额，不能为了比例降级真正重要的内容。

## 4. 对照来源复核

合并后进行一次与写作分开的核查；有条件时使用新 verifier，无法独立调用时重新打开来源逐项检查，不能声称完成了独立审阅。

核查并记录：

- 覆盖表中每个主题是否有对应内容，尤其是最后一个主题；排除项是否有理由。
- 所有核心公式、适用条件及代表性例题是否准确；重新计算关键结果。
- 每段抽查至少一个引用，另核查所有有歧义的页码和 OCR 数学内容；明确这属于抽查，不宣称所有引用均已核验。
- 来源内容与补充内容是否分明，中英术语、标签含义和图示是否准确。
- 文档是否能支持重做例题，而非只剩术语清单。
- 对图解过程至少重算一条完整轨迹，并检查并列优先级、重复状态处理及终止时机；若附自测题，逐题核对答案和来源。

记录结论 `通过 / 通过但有说明 / 存在阻塞问题`，列出问题、来源位置和修正。关键公式错误、漏掉主题或虚假引用必须修正。非阻塞的编辑建议不应造成无限重写。最多进行两轮修正复核；仍有问题时保留草稿并如实说明，不把部分覆盖称为完整完成。

## 5. 输出与验收

按 [references/output.md](references/output.md) 完成所选格式的写入与验收。成品开头记录来源、覆盖范围、页码规则和必要的未解决项。

最终回复提供实际存在的成品链接和简短说明。没有成功生成用户要求的格式时，说明已完成部分与具体阻塞，不将草稿、编译意图或过期 PDF 当作最终交付。
