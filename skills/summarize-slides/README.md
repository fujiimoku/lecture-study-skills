# Summarize Slides

把课件整理成中文考前复习笔记，保留英文术语、来源页码、重点标签和逐步例题。

```text
用 summarize-slides 整理这份课件，只要 Markdown，例题保留中间步骤。
```

默认交付 TeX + PDF；明确指定 Markdown、仅 TeX 或聊天输出时遵循请求。实际规则见 [SKILL.md](SKILL.md)，完整复制本目录即可安装，保留 references 和 LICENSE。
