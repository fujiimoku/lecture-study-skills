# 数据库课程的逐步例题规则

仅用于源课件包含关系代数、SQL、事务或相关数据操作的部分；不用于强迫其他学科按数据库格式写笔记。

## 小数据与中间结果

对投影、连接、除法、自连接、分组聚合等操作给出可手算的小表。优先保留课件原例；若原例太大，可另给标注清楚的“补充简化示例”，不要冒充原数据。

1. 展示输入表、字段含义和语义假设。
2. 给出形式表达式，并用一句中文解释。
3. 展示每个有教学价值的中间状态，说明哪些行被删除及原因。
4. 展示结果，重新核算行数和值。

自然连接示例可依次展示小规模笛卡尔积、公共属性相等的筛选、合并重复列；选择足够小的数据使全表可读。除法说明“对所有”的含义，自连接解释两个别名各扮演什么角色。不要把逻辑教学步骤说成数据库真实物理执行计划。

## SQL 不能丢失的语义

- 明确区分关系代数集合语义与 SQL 默认多重集语义；投影去重不能直接等同于没有 DISTINCT 的 SELECT。
- 逐句解释查询；WHERE 是分组前筛选，HAVING 是分组后筛选。涉及 NULL 时说明三值逻辑，并检查 COUNT(*) 与 COUNT(column) 的区别。
- 使用可执行的标识符，例如 `customer_name`；课件若使用带连字符的列名，说明需要按数据库方言引用。
- UNIQUE、NULL、LIKE 大小写敏感性、排序规则和正则语法可能依数据库方言而异。课件未指定时说明假设，不把一个环境的行为当作通用规则。
- 对 WHERE/HAVING、UNION/UNION ALL 等容易混淆的概念，使用同一组输入并列展示结果差异。
- 对 LIKE/正则/glob 给出“模式—匹配—不匹配”表，并注明适用语法和大小写假设；不能混用通配符规则。

例如，关系代数中对院系字段投影后保留不同值；SQL 中 `SELECT dept_name FROM instructor` 仍可能重复，`SELECT DISTINCT dept_name FROM instructor` 才明确去重。

对事务调度保留执行顺序、读写对象和冲突边；补充例子需核对是否确实满足所声称的可串行化或恢复性质。
