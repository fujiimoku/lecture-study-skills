# Lecture Tutor

把课件展开为可自学的详细讲义，结合严谨陈述、直观解释和页码定位，明确区分课件证明与补充证明。

```text
用 lecture-tutor 详细讲解这份课件，生成 TeX 和 PDF。
```

默认交付 TeX + PDF，也尊重明确指定的其他格式。实际规则见 [SKILL.md](SKILL.md)，完整复制本目录即可安装，保留 references 和 LICENSE。

基于 [lecture-tutor-skill](https://github.com/Epiphanythu/lecture-tutor-skill) 修订。原作者 MIT 许可见 [LICENSE](LICENSE)。维护版本：[fujiimoku/lecture-study-skills](https://github.com/fujiimoku/lecture-study-skills)。
